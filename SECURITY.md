# Security policy

This is an early-stage project. Do not include secrets, private memory, personal data, local service URLs, or private agent configuration in public issues, discussions, or pull requests.

For a vulnerability that could affect a real deployment, use GitHub's private vulnerability reporting for this repository if available. If it is not enabled, contact the repository owner through a private channel. Include a minimal reproduction and impact assessment; do not publish exploit details before coordinating a fix.

The project does not yet define a supported production deployment or security-response SLA. Do not assume that experimental code is safe for sensitive data or autonomous operation.
